In plain words

Three steps. No jargon required to understand any of them.

1 — Watch

It counts people, honestly.

A camera or a photo tells it how many people are arriving and how fast — the same way a steward would, just faster and all the time.

2 — Predict

It plays the next two minutes forward.

Not what's crowded now — what will be crowded, up to 120 seconds before it happens, using the same physics real crowd-safety engineers use.

3 — Redirect

It says exactly what to do.

One plain sentence to a steward: which gate to hold, which route to open, and for how long. Not a dashboard to interpret — an instruction to follow.

Controls

V4 — cinematic scroll hero, broken-center layout, 8pt spacing grid. Type is Martian Grotesk / Martian Grotesk Condensed / Martian Mono, evilmartians.com's own open-source typefaces (OFL-1.1), embedded as base64 so the page needs nothing from a font CDN. Color is unchanged from the approved v3 palette — OKLCH tokens grouped by job (elevation / border / content / UI / data) — extended with a plain-language color key above so meaning never depends on guessing a hue. Layout no longer centers on a single column: prose sections pin to a left rail at a 640px reading width, instrument sections widen to 1360px, and neither is horizontally centered — the asymmetry is deliberate, not a bug. Every spacing value on the page is a multiple of the 8px scale (--sp-1 through --sp-11), with 4px reserved only for icon-to-label gaps. The cinematic hero's four media layers, the six commercial-storyboard frames, and all four "related coverage" cards are gradient stand-ins carrying a data-prompt with the exact shot to generate — real photography and video are one step away, pending video/image-generation access; the 15-second script itself is finished and lives alongside this file. Motion is real CSS/JS, respects prefers-reduced-motion throughout, and the scroll-driven hero degrades to a static first frame when motion is reduced.
